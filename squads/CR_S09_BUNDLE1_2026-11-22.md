# S09 Bundle 1 — Change Requests (2026-11-22)

Owner: S09 (memory, notes-files, projects). Status: **proposed only**. This bundle does not edit `api/`, `packages/contracts`, `vercel.json`, S22 power data, or apply a database migration.

## CR-1 — LEAD/S00: mount S09 actions in the existing shared function

Do not create another `api/` file. Add the three rewrites below to the existing `vercel.json` rewrites, preserving all existing entries:

```json
{ "source": "/api/memory/:action", "destination": "/api/tasks?action=:action" },
{ "source": "/api/notes-files/:action", "destination": "/api/tasks?action=:action" },
{ "source": "/api/projects/:action", "destination": "/api/tasks?action=:action" }
```

The `api/tasks/index.ts` dispatcher must branch on the S09 action names after owner-session verification and JSON parsing, before its S08 task/reminder switch. Build a fresh `Request` for the feature handler because the existing request body has already been consumed:

```ts
const featureRequest = new Request(request.url, {
  method: 'POST',
  headers: request.headers,
  body: JSON.stringify(body),
});
const featureContext = {
  ownerId: owner.user.id,
  memoryStore,                 // SupabaseMemoryStore constructed for this owner + user JWT
  memoryService,               // same store; no embedder; embed mode off; emit async no-op
  decideMemoryCandidate,       // packages/memory `decide(candidate, { kill: 'off', now })`; pure function only
  classifyMemoryText,          // packages/memory `classify()` adapter
  findMemorySecrets,           // packages/memory `findSecrets()` adapter
  db,                           // owner-scoped PostgREST adapter described below
  storageCreateUploadUrl,      // owner-token signed PUT for private `files` bucket
  storageRemove,               // owner-token Storage delete
  runPower,                    // CR-2 registered-power + kill + audit adapter
};
const response = await feature.handle(action, featureRequest, featureContext);
return withCookie(response, owner.setCookie);
```

`memoryService` must use the exact same owner-bound store as `memoryStore`; configure no `embedder`, `embedMode: () => 'off'`, `emit: async () => {}`, and no private summarizer/reminder callbacks. This bundle must not call `packages/model-gateway` or `packages/models`. `decideMemoryCandidate` is a pure adapter over the existing `packages/memory/src/policy.ts` `decide()` function; it is needed so a shared-S08-only private hit is policy-checked and inserted directly as T2 (never briefly written as normal/T1).

`db({ table, method, query, body, prefer })` must construct PostgREST requests with the authenticated owner's **user access token** in `Authorization: Bearer ...`, the public anon key in `apikey`, and force `owner_id=eq.<session-user-id>` after all supplied query filters so callers cannot override it. Do not use a service-role key in app/serverless request code. Reject table names outside `projects`, `notes`, `files`, and `memory_links`; allow only the HTTP methods required by these handlers. The database's existing `owner_all` RLS policies remain a second guard.

The current S08 body parser caps requests at 12 KB. Keep that cap for every existing S08 action and every S09 action **except** `workspace.notes.create` and `workspace.notes.update`; allow those two actions up to 110 KB (the text field is capped at 100 KB). File bytes never pass through the shared function: browser performs the signed Storage `PUT` directly, then calls the small JSON `complete-upload` action. Reject all other over-limit bodies before feature dispatch.

### Exact action contract

All routes are `POST`, owner-authenticated, `cache-control: no-store`, and use the normal `{ ok: true, data }` / `{ ok: false, error }` envelope, except `memory.export`, which returns an NDJSON attachment containing **normal-tier rows only**. Query values (`id`, `q`, `limit`, `offset`) are query-string parameters on the POST route.

**Memory — `/api/memory/:action`**

| Action | Request | Data response |
|---|---|---|
| `memory.list` | `?limit=1..100&offset=0..` (both optional) | `{ normal: MemoryItem[], private: PrivatePlaceholder[], total, counts }` |
| `memory.get` | `?id=UUID` | `MemoryItem` or `PrivatePlaceholder` |
| `memory.remember` | `{ text: string(1..2000), title?: string(1..200), kind?: Kind, tags?: string[], pinned?: boolean, private?: boolean, confirmed: boolean }` | `{ saved: true, deduped: boolean, item: MemoryItem \| PrivatePlaceholder }` |
| `memory.update` | `{ id: UUID, revision: integer, title?: string, body?: string, tags?: string[], private?: boolean, confirmed: boolean }` | `MemoryItem` or `PrivatePlaceholder` |
| `memory.forget` | `{ id: UUID, confirmed: true }` | `{ deleted, derived_deleted, links_deleted }` |
| `memory.forget-all` | `{ expectedCount: integer, confirmed: true }` | `{ deleted, derived_deleted, links_deleted }` |
| `memory.export` | `{ confirmed: true }` | `application/x-ndjson`, normal rows only; never private rows |
| `memory.stats` | `{}` | owner-only count summary; no row text |

`Kind` is one of `fact`, `profile`, `preference`, `routine`, `project`, `episode`, `knowledge`, `person`. `MemoryItem` is the existing safe normal projection. `PrivatePlaceholder` is exactly `{ id, label: 'Private item', badge: 'private', updated_at }`; do not add title/body/tags/reason/category/source/filename/path/excerpt. Password/OTP/ID/card/bank/API-secret-like values are refused, not stored.

**Notes and files — `/api/notes-files/:action`**

| Action | Request | Data response |
|---|---|---|
| `workspace.notes.list` | `{}` | `{ normal: Note[], private: PrivatePlaceholder[], counts }` |
| `workspace.notes.get` | `?id=UUID` | `Note` or `PrivatePlaceholder` |
| `workspace.notes.create` | `{ title: string(1..200), body_md?: string(max 100000), tags?: string[], project_id?: UUID|null, pinned?: boolean, private?: boolean, confirmed: boolean }` | `Note` or `PrivatePlaceholder` |
| `workspace.notes.update` | `{ id: UUID, revision: integer, title?: string, body_md?: string(max 100000), tags?: string[], pinned?: boolean, private?: boolean, confirmed: boolean }` | `Note` or `PrivatePlaceholder` |
| `workspace.notes.delete` | `{ id: UUID, confirmed: true }` | `{ deleted: boolean }` |
| `workspace.files.list` | `{}` | `{ normal: [], private: PrivatePlaceholder[], counts, upload_note }` (all files remain private) |
| `workspace.files.upload-url` | `{ name: string(1..200), mime: allow-listed MIME, size_bytes: 1..10485760, project_id?: UUID|null, tags?: string[], confirmed: true }` | `{ id, upload: { method: 'PUT', url, headers }, private: true }` |
| `workspace.files.complete-upload` | `{ id: UUID, sha256: 64-hex, confirmed: true }` | `{ id, status: 'quarantined', label: 'Private file', badge: 'private' }` |
| `workspace.files.delete` | `{ id: UUID, confirmed: true }` | `{ deleted: boolean }` |
| `workspace.search` | `?q=string(1..120)` | `{ normal: Note[], private: [], counts }` (normal tier only) |

File MIME allow-list: `text/plain`, `text/markdown`, `application/pdf`, `image/png`, `image/jpeg`, `text/csv`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document`. Maximum file size 10 MiB. Storage object path starts with the owner UUID. Files stay `private=true`, `tier='sensitive'`, `no_embed=true`, `tokens=[]`, `status='quarantined'` after completion. No file preview, download, OCR, text extraction, indexing or embedding until S19 approves a scanner/vault flow. Never log or persist the signed URL/token in `decisions` or application logs.

## CR-3 — LEAD: accept the owner-only shared handler adapter

The handler context is feature-local; it is not a bypass around the owner API. LEAD must supply:

- `ownerId`: authenticated session user id only.
- `memoryStore`: one `SupabaseMemoryStore` per owner, constructed with owner UUID + owner session JWT + anon key; no service role.
- `memoryService`: same store instance; no embedder, embeddings explicitly off, emit no-op, no sensitive summarizer/reminder callback.
- `decideMemoryCandidate`: existing package `decide(candidate, { kill: 'off', now })`; no model/network.
- `classifyMemoryText` and `findMemorySecrets`: adapters to existing `packages/memory/src/classify.ts` and `redact.ts`.
- `db`: owner-filtered PostgREST with user bearer and anon `apikey`; allowed table names only; enforce owner filter after caller filters.
- `storageCreateUploadUrl` and `storageRemove`: Supabase Storage private `files` bucket with user bearer; enforce owner UUID prefix in object path.
- `runPower`: CR-2 implementation.

The S08 shared `classifySensitivity()` is imported directly by the shared S09 privacy helper; do not create a second classifier. `packages/memory` policy/classifier is an additional guard. T2 is stored and rendered without any model call. Anything that would require a model on private text must remain **abhi band** until a separately accepted local-model/vault path exists.
