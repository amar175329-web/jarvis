# UI/UX Design Brief - look and feel (living doc)
STATUS: DRAFT v0.1 | OWNER: S06 (shell) with S21 (personality) | UPDATED: 2026-11-10
Amit has not yet given a visual taste: collect it before designing (ask ONE question at a time).

## Principles
1. Calm, quiet, "JARVIS" feel: dark-first, clear, not busy. 2. Hindi (Devanagari) first, Hinglish allowed in labels. 3. Big, simple buttons; phone first. 4. Always visible: power-off, kill state, current power level. 5. Confirmation text short: WHAT + TO WHOM + UNDO.
## Voice UI
Mic button, listening/speaking states, stop word works anytime, subtitles on by default.
## To decide with Amit
Colors and logo | font (Devanagari-friendly) | light mode needed? | animations level | density (compact vs roomy).
## Deliverable
Design system (tokens: colors, type, spacing) + screens in the Design tool, then app/ components follow it.
