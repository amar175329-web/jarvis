# App Flow - navigation + user journeys (living doc)
STATUS: DRAFT v0.1 | OWNER: S07 (chat) + S06 (shell/quick) | UPDATED: 2026-11-10

## 1. Screens (first cut)
Login -> Home/Today -> Chat (default) | Tasks+Reminders | Memory/Knowledge | Boards | Devices | Bots | Extend | Settings (Prefs, Models, Security, Backup) | Safety Center | Power-off button (always visible).

## 2. Core journeys
1. First run: owner login -> set owner fingerprint (once, inside owner login) -> pick voice (calm = JARVIS) -> Today.
2. Talk: tap mic -> JARVIS listens -> brain router (FAST/NORMAL/DEEP) -> answer in Hindi voice + text.
3. Act with confirm (L2): JARVIS says what + to whom + undo, "...karun?" -> Amit says "हाँ/कर दो" -> done -> logged with "why".
4. Sensitive (money/health/password): phone voice "हाँ" -> fingerprint -> both or nothing.
5. JARVIS speaks first: watcher fires -> brain checks focus mode / quiet hours / cooldown -> speaks or stays silent.
6. Kill: Power-off button or device -> everything cancelled now; only a human turns it back on.
7. "Tumne ye kyun kiya?" -> explain from the decisions table.

## 3. Rules
Every screen shows kill state. Every action shows its power level. Back/undo always visible after L2/L3 actions.
